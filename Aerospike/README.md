# Aerospike

Aerospike is a distributed key-value DBMS. It is mainly targeted at OLTP workloads with large number of transactions. It is developed by a company of the same name. [07] [08]

## 基本信息

- **数据库类型**: 文档、图、KV、空间
- **所属机构**: Aerospike
- **许可证**: AGPL v3
- **首次发布**: 2012
