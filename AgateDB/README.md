# AgateDB

AgateDB is an embeddable, persistent key-value DBMS written in Rust. It is built by Pingcap as a replacement for TiKV .

## 基本信息

- **数据库类型**: KV
- **所属机构**: PingCAP
- **许可证**: Apache v2
- **首次发布**: 2019
- **国家/地区**: CN
