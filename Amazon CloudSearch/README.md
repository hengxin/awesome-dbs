# Amazon CloudSearch

A hosted search engine service by Amazon with the data stored in Amazons cloud

## 基本信息

- **数据库类型**: 搜索
- **所属机构**: Amazon
- **许可证**: 商业或开源（DB-Engines 未给出具体许可证）
- **首次发布**: 2012
