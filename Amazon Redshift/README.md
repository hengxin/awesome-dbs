# Amazon Redshift

Large scale data warehouse service for use with business intelligence tools

## 基本信息

- **数据库类型**: SQL
- **所属机构**: Amazon (based on PostgreSQL )
- **许可证**: 商业或开源（DB-Engines 未给出具体许可证）
- **首次发布**: 2012
