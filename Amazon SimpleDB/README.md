# Amazon SimpleDB

Hosted simple database service by Amazon, with the data stored in the Amazon Cloud. There is an unrelated product called SimpleDB developed by Edward Sciore

## 基本信息

- **数据库类型**: KV
- **所属机构**: Amazon
- **许可证**: 商业或开源（DB-Engines 未给出具体许可证）
- **首次发布**: 2007
