# Apache Druid

Open-source analytics data store designed for sub-second OLAP queries on high dimensionality and high cardinality data

## 基本信息

- **数据库类型**: SQL、时序
- **所属机构**: Apache Software Foundation and contributors
- **许可证**: 商业或开源（DB-Engines 未给出具体许可证）
- **首次发布**: 2012
