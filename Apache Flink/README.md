# Apache Flink

A framework and distributed processing engine for stateful computations over unbounded and bounded data streams, delivering full database capabilities with the addition of Table Store.

## 基本信息

- **数据库类型**: SQL
- **所属机构**: Apache Software Foundation and contributors
- **许可证**: 商业或开源（DB-Engines 未给出具体许可证）
