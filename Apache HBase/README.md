# Apache HBase

Wide-column store based on Apache Hadoop and on concepts of BigTable

## 基本信息

- **数据库类型**: 宽列
- **所属机构**: Apache Software Foundation Apache top-level project, originally developed by Powerset
- **许可证**: 商业或开源（DB-Engines 未给出具体许可证）
- **首次发布**: 2008
