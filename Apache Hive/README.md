# Apache Hive

data warehouse software for querying and managing large distributed datasets, built on Hadoop

## 基本信息

- **数据库类型**: SQL
- **所属机构**: Apache Software Foundation initially developed by Facebook
- **许可证**: 商业或开源（DB-Engines 未给出具体许可证）
- **首次发布**: 2012
