# Apache Jena - TDB

A RDF storage and query DBMS, shipped as an optional-use component of the Apache Jena framework

## 基本信息

- **数据库类型**: RDF
- **所属机构**: Apache Software Foundation originally developed by HP Labs
- **许可证**: 商业或开源（DB-Engines 未给出具体许可证）
- **首次发布**: 2000
