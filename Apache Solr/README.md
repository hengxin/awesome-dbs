# Apache Solr

A widely used distributed, scalable search engine based on Apache Lucene

## 基本信息

- **数据库类型**: 搜索、空间
- **所属机构**: Apache Software Foundation
- **许可证**: 商业或开源（DB-Engines 未给出具体许可证）
- **首次发布**: 2006
