# BaikalDB

BaikalDB is a distributed OLTP database system created by Baidu.

## 基本信息

- **数据库类型**: SQL
- **所属机构**: Baidu, Inc.
- **许可证**: Apache v2
- **首次发布**: 2018
- **国家/地区**: CN
