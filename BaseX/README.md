# BaseX

BaseX is a light-weight XML database management system and XQuery processor.

Light-weight Native XML DBMS with support for XQuery 3.0 and interactive GUI.

## 基本信息

- **数据库类型**: XML
- **所属机构**: BaseX GmbH
- **许可证**: BSD License
- **首次发布**: 2007
