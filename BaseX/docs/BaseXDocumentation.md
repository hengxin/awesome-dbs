# Main Page
[](/main/media/BaseX-Screenshot.png)
[BaseX](https://basex.org/) is a lightweight, high-performance and scalable XML Database and an XQuery 4.0 Processor with full support for the W3C Update and Full-Text extensions. It allows you to store, query and process large corpora of textual (XML, HTML, JSON, CSV, others) and binary resources. The GUI provides an IDE for writing complex applications, as well as various visualizations for interactively exploring your data. RESTXQ enables the development of web applications in XQuery. BaseX is platform-independent and BSD-licensed (see [Wikipedia](https://en.wikipedia.org/wiki/BaseX) for more information).
