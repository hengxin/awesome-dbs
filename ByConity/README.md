# ByConity

ByConity is a cloud-native OLAP DBMS based on Clickhouse.

## 基本信息

- **数据库类型**: OLAP
- **所属机构**: ByteDance Ltd.
- **许可证**: Apache v2
- **首次发布**: 2020
- **国家/地区**: CN
