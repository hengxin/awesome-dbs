# Calvin

Calvin is a scalable transactional database system that leverages determinism to guarantee active replication and full ACID-compliance of distributed transactions without two-phase commit.

## 基本信息

- **数据库类型**: SQL
- **所属机构**: Yale University
- **首次发布**: 2012
- **国家/地区**: US
