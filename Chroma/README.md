# Chroma

Chroma is a document-oriented DBMS designed to support the generation and searches on embeddings generated from LLMs.

Chroma is an open-source vector DBMS.

## 基本信息

- **数据库类型**: 向量
- **所属机构**: Chroma
- **许可证**: Apache v2
- **首次发布**: 2022
