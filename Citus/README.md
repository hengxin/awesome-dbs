# Citus

Citus is an extension to Postgres to make it a distributed, shared-nothing DBMS.

Scalable hybrid operational and analytics RDBMS for big data use cases based on PostgreSQL

## 基本信息

- **数据库类型**: SQL、文档、OLAP
- **所属机构**: Citus Data, Inc.
- **许可证**: AGPL v3
- **首次发布**: 2010
