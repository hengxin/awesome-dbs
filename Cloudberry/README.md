# Cloudberry

Cloudberry (sometimes referred to as "CloudberryDB" or "CBDB") is a fork of Greenplum.

## 基本信息

- **数据库类型**: OLAP
- **所属机构**: HashData Technology Limited
- **许可证**: Apache v2
- **首次发布**: 2023
- **国家/地区**: CN
