# CnosDB

CnosDB is a distributed time-series database management system written in Rust.

## 基本信息

- **数据库类型**: 时序
- **所属机构**: CnosDB
- **许可证**: AGPL v3
- **首次发布**: 2022
- **国家/地区**: CN
