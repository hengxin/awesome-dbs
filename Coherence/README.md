# Oracle Coherence

Oracle Coherence is a Java-based distributed cache and in-memory data grid developed by Oracle Corporation. It provides key-value object storage with optional persistence, automatic sharding, polyglot and REST interfaces, querying, transactions, eventing, and multi-site federation for clustered environments.
