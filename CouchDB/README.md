# CouchDB

- [CouchDB](https://couchdb.apache.org/)

- [CouchDB Consistency Features](https://quabase.sei.cmu.edu/mediawiki/index.php/CouchDB_Consistency_Features)

CouchDB (" c luster o f u nreliable c ommodity h ardware") is a document-oriented NoSQL DBMS.

## 基本信息

- **数据库类型**: 文档、空间
- **所属机构**: Apache Software Foundation Apache top-level project, originally developed by Damien Katz, a former Lotus Notes developer
- **许可证**: Apache v2
- **首次发布**: 2005
- **国家/地区**: US
