# Couchbase

Couchbase is an open-source, distributed NoSQL document database. It supports the Memcached client protocol and provides extra features like disk persistence, data replication. [05]

## 基本信息

- **数据库类型**: 文档、向量、KV、空间、搜索、时序、宽列
- **所属机构**: Couchbase, Inc.
- **许可证**: Apache v2
- **首次发布**: 2011
- **国家/地区**: US
