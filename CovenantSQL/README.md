# CovenantSQL

CovenantSQL is a decentralized SQL database management system derived from SQLite and built on top of a blockchain. It supports most of the SQL-92 features. Each party interacting with CovenantSQL is either a client, a block producer, or a miner: [05] [06] [07]

## 基本信息

- **数据库类型**: SQL
- **所属机构**: Covenant Labs
- **许可证**: Apache v2
- **首次发布**: 2018
- **国家/地区**: CN
