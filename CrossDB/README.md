# CrossDB

CrossDB is a proprietary embedded DBMS for C/C++ applications.

## 基本信息

- **数据库类型**: 嵌入式
- **所属机构**: JC Wang
- **许可证**: Proprietary
- **首次发布**: 2019
- **国家/地区**: CN
