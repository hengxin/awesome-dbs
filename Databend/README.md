# Databend

Databend is distributed SQL execution engine for shared-disk storage.

## 基本信息

- **数据库类型**: SQL、OLAP
- **所属机构**: Databend Labs
- **许可证**: Apache v2
- **首次发布**: 2021
- **国家/地区**: CN
