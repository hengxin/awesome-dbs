# Databricks

The Databricks Lakehouse Platform combines elements of data lakes and data warehouses to provide a unified view onto structured and unstructured data. It is based on Apache Spark.

## 基本信息

- **数据库类型**: 文档、SQL、OLAP
- **所属机构**: Databricks
- **许可证**: Proprietary
- **首次发布**: 2013
