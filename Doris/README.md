# Doris

Doris is a parallel SQL data warehouse developed by Baidu.

## 基本信息

- **数据库类型**: OLAP
- **所属机构**: Baidu, Inc.
- **许可证**: Apache v2
- **首次发布**: 2017
- **国家/地区**: CN
