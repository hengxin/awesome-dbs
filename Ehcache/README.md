# Ehcache

Ehcache is an open source Java distributed cache for general purpose caching.

A widely adopted Java cache with tiered storage options

## 基本信息

- **数据库类型**: KV
- **所属机构**: Terracotta Inc, owned by Software AG
- **许可证**: Apache v2
- **首次发布**: 2009
