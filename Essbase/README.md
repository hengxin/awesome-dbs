# Oracle Essbase

Essbase ("extended spreadsheet database") is a multidimensional database management system that provides a database platform for building analytic applications.

Multidimensional database platform for analytic applications

## 基本信息

- **数据库类型**: OLAP
- **许可证**: Proprietary
- **首次发布**: 1992
- **国家/地区**: US
