# EuclidOLAP

EuclidOLAP is an in-memory multi-dimensional database management system for data cubes.

## 基本信息

- **数据库类型**: OLAP
- **所属机构**: Chen Zhigang
- **许可证**: Apache v2
- **首次发布**: 2022
- **国家/地区**: CN
