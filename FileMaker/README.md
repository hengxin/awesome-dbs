# FileMaker

FileMaker is a proprietary relational database application which can be used in a cross-platform environment. Users can create custom applications with a graphical user interface easily. FileMaker supports convenient data exchange with other web applications by cURL, JSON functions, and REST-based API. It can also connect to a number of SQL databases including MySQL, Oracle, and Microsoft SQL as…

FileMaker is a cross-platform RDBMS that includes a GUI frontend.
