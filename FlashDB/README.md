# FlashDB

FlashDB is an embedded key-value DBMS.

## 基本信息

- **数据库类型**: KV、嵌入式
- **所属机构**: Armink
- **许可证**: Apache v2
- **首次发布**: 2020
- **国家/地区**: CN
