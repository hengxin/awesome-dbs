# GBase

GBase is a distributed column store DBMS.

Widely used RDBMS in China, including analytical, transactional, distributed transactional, and cloud-native data warehousing.

## 基本信息

- **数据库类型**: SQL
- **所属机构**: General Data Technology Co., Ltd.
- **许可证**: Proprietary
- **首次发布**: 2004
- **国家/地区**: CN
