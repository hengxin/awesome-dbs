# Galaxybase

Galaxybase is a distributed graph database system written in Java.

## 基本信息

- **数据库类型**: 图
- **所属机构**: Chuanglin(Createlink) Technology Co., Ltd 浙江创邻科技有限公司
- **许可证**: Proprietary
- **首次发布**: 2017
- **国家/地区**: CN
