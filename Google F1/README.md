# Google F1

## papers
- [F1: A Distributed SQL Database that Scales @ VLDB2013](https://dl.acm.org/doi/10.14778/2536222.2536232)
- [F1 Query: Declarative Querying at Scale @ VLDB2018](http://www.vldb.org/pvldb/vol11/p1835-samwel.pdf)

## articles
- [从Google F1 看HTAP数据库的诞生 @ zhihu](https://zhuanlan.zhihu.com/p/157802589)

F1 is a relational distributed transactional database. And it's built on Google's Spanner so that it can reach strong consistency. It combines RDBMS features and NoSQL scalability. And it maintains ACID guarantees and provides a distributed scalable database system.
