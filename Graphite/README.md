# Graphite

Data logging and graphing tool for time series data The storage layer (fixed size database) is called Whisper

## 基本信息

- **数据库类型**: 时序
- **所属机构**: Chris Davis
- **许可证**: 商业或开源（DB-Engines 未给出具体许可证）
- **首次发布**: 2006
