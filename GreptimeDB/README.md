# GreptimeDB

GreptimeDB is a distributed time-series DBMS written in Rust.

## 基本信息

- **数据库类型**: 时序
- **所属机构**: Greptime Inc.
- **许可证**: Apache v2
- **首次发布**: 2022
- **国家/地区**: CN
