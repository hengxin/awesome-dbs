# HexaDB

HexaDB is an HTAP system that is compatible with Postgres.

## 基本信息

- **数据库类型**: SQL、HTAP
- **所属机构**: Shuyi Technology (Beijing) Co.
- **许可证**: Proprietary
- **首次发布**: 2023
- **国家/地区**: CN
