# HoraeDB

HoraeDB is a distributed, schema-less, time-series DBMS.

## 基本信息

- **数据库类型**: 时序
- **所属机构**: Ant Group
- **许可证**: Apache v2
- **首次发布**: 2021
- **国家/地区**: CN
