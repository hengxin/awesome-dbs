# HyperSQL

HSQLDB ( Hyper SQL Database ) is a relational database management system written in Java.

## 基本信息

- **数据库类型**: SQL
- **所属机构**: HSQLDB Development Group
- **许可证**: BSD License
- **首次发布**: 2001
- **国家/地区**: US
