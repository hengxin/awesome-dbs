# IBM-Db2-pureScale

IBM Db2 is a relational database management system that is focused on transactional and warehousing workloads.

## 基本信息

- **数据库类型**: SQL、文档、空间
- **所属机构**: IBM
- **许可证**: Proprietary
- **首次发布**: 1983
- **国家/地区**: US
