# IceFireDB

IceFireDB is as distributed NoSQL key/value DBMS that supports the Redis wire protocol.

## 基本信息

- **数据库类型**: KV
- **所属机构**: Li Biao
- **许可证**: Apache v2
- **首次发布**: 2021
- **国家/地区**: CN
