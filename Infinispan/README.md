# Infinispan

Infinispan is a distributed cache and key-value NoSQL storage system developed by Red Hat.

## 基本信息

- **数据库类型**: KV
- **所属机构**: Red Hat, Inc.
- **许可证**: Apache v2
- **首次发布**: 2009
- **国家/地区**: US
