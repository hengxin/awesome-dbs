# InfluxDB

InfluxDB is an open source time series database built by InfluxData. Optimized for the storage and retrieval of time series data, it is used for monitoring and recording performance metrics and analytics.

DBMS for storing time series, events and metrics

## 基本信息

- **数据库类型**: 时序、空间
- **所属机构**: InfluxData
- **许可证**: MIT License
- **首次发布**: 2013
- **国家/地区**: US
