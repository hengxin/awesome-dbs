# Ingres

Ingres is one of the first ever relational database management systems (DBMSs). Actian Corporation currently oversees the development of the database while providing certified binaries and support. The latest version is Ingres 11, which is also known commercially as the Actian X Hybrid Database. It is mainly intended for OLTP tasks, but the latest version has support for columnar storage which is…

Well established RDBMS

- **数据库类型**: SQL
- **所属机构**: Actian Corporation
- **许可证**: Proprietary
