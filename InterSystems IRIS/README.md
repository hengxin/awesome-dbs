# InterSystems IRIS

A containerised multi-model DBMS, interoperability and analytics data platform with wide capabilities for vertical and horizontal scalability

## 基本信息

- **数据库类型**: 文档、KV、SQL
- **所属机构**: InterSystems
- **许可证**: 商业或开源（DB-Engines 未给出具体许可证）
- **首次发布**: 2018
