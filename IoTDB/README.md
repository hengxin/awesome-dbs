# IoTDB

IoTDB is a specialized database management system for time series data generated by a network of IoT devices with low computational power. It targets a workload that has high-frequency data write, large-volume data storage, and complex analytical queries. IoTDB supports queries that are common in monitoring and collecting metrics in IoT devices, namely filtering by predicates, query by time…

## 基本信息

- **数据库类型**: 时序
- **所属机构**: Tsinghua University
- **许可证**: Apache v2
- **首次发布**: 2017
- **国家/地区**: CN
