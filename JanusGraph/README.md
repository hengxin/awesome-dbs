# JanusGraph

JanusGraph is a transactional graph DBMS optimized for storing and querying graphs distributed across a multi-machine cluster.

## 基本信息

- **数据库类型**: 图
- **所属机构**: Linux Foundation; originally developed as Titan by Aurelius
- **许可证**: Apache v2
- **首次发布**: 2017
- **国家/地区**: US
