# Kunlun

Kunlun distributed relational DBMS design for OLTP workloads. It is based on a fork of PostgreSQL.

## 基本信息

- **数据库类型**: SQL
- **所属机构**: Zetuo Technology Co., Ltd.
- **许可证**: Commons Clause License
- **首次发布**: 2019
- **国家/地区**: CN
