# Kvrocks

Kvrocks is a distributed key-value DBMS that is compatible with the Redis wire protocol.

## 基本信息

- **数据库类型**: KV
- **所属机构**: Meitu
- **许可证**: Apache v2
- **首次发布**: 2019
- **国家/地区**: CN
