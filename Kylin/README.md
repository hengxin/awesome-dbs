# Kylin

Kylin is an open source distributed data analytics engine on top of SparkSQL/Hive. It offers SQL interface to do OLAP on large datasets. Kylin is not a replacement for a massive parallel processing engine like Hive and Presto. It runs on top of these systems as a query accelerator. [04] [06] [07]

## 基本信息

- **数据库类型**: OLAP
- **所属机构**: eBay Inc.
- **许可证**: Apache v2
- **首次发布**: 2013
- **国家/地区**: CN
