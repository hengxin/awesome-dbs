# Kyuubi

Kyuubi is a middleware that provides a standardized SQL interface to different query engines. It translates SQL requests over Thrift into the SQL supported by the backing system.

## 基本信息

- **数据库类型**: SQL
- **许可证**: Apache v2
- **首次发布**: 2017
- **国家/地区**: CN
