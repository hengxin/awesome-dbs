# LotusDB

LotusDB is a embedded, log-structured key-value DBMS written in Go. [04]

## 基本信息

- **数据库类型**: SQL
- **所属机构**: Rose Duan
- **许可证**: Apache v2
- **首次发布**: 2021
- **国家/地区**: CN
