# MMKV

MMKV is a mobile key-value storage framework developed by Tencent for the WeChat application. It targets Android, iOS, macOS, Windows, POSIX, and HarmonyOS platforms. The system utilizes memory-mapped files to synchronize data between memory and disk, and employs Protocol Buffers for value encoding and decoding. It provides an application programming interface that persists changes immediately…
