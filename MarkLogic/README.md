# MarkLogic

MarkLogic is a multi-model DBMS that supports document (XML) and graph (RDF) data.

Operational and transactional Enterprise NoSQL database

## 基本信息

- **数据库类型**: 文档、搜索、向量
- **所属机构**: MarkLogic Corp.
- **许可证**: Proprietary
- **首次发布**: 2001
