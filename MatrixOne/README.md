# MatrixOne

MatrixOne is an HTAP DBMS written in Go.

## 基本信息

- **数据库类型**: SQL、OLAP、流
- **所属机构**: MatrixOrigin Inc.
- **许可证**: Apache v2
- **首次发布**: 2021
- **国家/地区**: CN
