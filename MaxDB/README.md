# MaxDB

MaxDB is a relational DBMS developed by SAP.

## 基本信息

- **数据库类型**: SQL
- **所属机构**: SAP, acquired from Software AG (Adabas-D) in 1997
- **许可证**: Proprietary
- **首次发布**: 1984
