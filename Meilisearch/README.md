# Meilisearch

Meilisearch is a document-oriented search engine.

A powerful, fast, open-source and highly customizable Search Engine

## 基本信息

- **数据库类型**: 搜索、向量
- **所属机构**: Meilisearch SAS
- **许可证**: MIT License
- **首次发布**: 2020
