# Memgraph documentation
Memgraph is a high-performance, in-memory graph database that powers real-time
AI context. It serves as the graph engine for GraphRAG pipelines, AI memory
systems and agentic workflows. The same architecture drives real-time graph
analytics, such as fraud detection, network analysis and infrastructure
monitoring.
## Get started[](#get-started)
Start Memgraph and run your first query in a few minutes, by hand or with your
coding agent. To let the agent write Memgraph code from the current docs, give it the
[Agent Skills](/docs/getting-started/coding-with-ai/skills) and the [docs MCP
server](/docs/getting-started/coding-with-ai/docs-mcp).
[Getting started](/docs/getting-started)[AI coding assistants](/docs/getting-started/coding-with-ai)[Installation](/docs/getting-started/install-memgraph)
