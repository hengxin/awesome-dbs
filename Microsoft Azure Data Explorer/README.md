# Microsoft Azure Data Explorer

Fully managed big data interactive analytics platform

## 基本信息

- **数据库类型**: SQL、文档、图、空间、搜索、时序
- **所属机构**: Microsoft
- **许可证**: 商业或开源（DB-Engines 未给出具体许可证）
- **首次发布**: 2019
