# Milvus

Milvus is a vector DBMS design to to store vectors generated by machine learning models and neural networks.

A DBMS designed for efficient storage of vector data and vector similarity searches

## 基本信息

- **数据库类型**: 向量
- **所属机构**: The Milvus Project
- **许可证**: Apache v2
- **首次发布**: 2019
- **国家/地区**: CN
