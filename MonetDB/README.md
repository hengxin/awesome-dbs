# MonetDB

MonetDB is an open-source column-oriented relational database management system developed at Centrum Wiskunde & Informatica (CWI) in the Netherlands. It targets analytical workloads, online analytical processing (OLAP), data mining, geographic information systems, RDF storage, text retrieval, and sequence alignment processing.
