# mongodb

Research on MongoDB

MongoDB is an open-source, cross-platform document-oriented DBMS store. It is a document database storing strongly typed objects with optional levels of schema validation. Ad hoc queries, indexing, and real time aggregation provide different ways to access and analyze the data. It is a distributed database at its core that provides high availability, horizontal scaling, and geographic…

## 基本信息

- **数据库类型**: 文档、KV、空间、搜索、时序、向量
- **所属机构**: MongoDB, Inc
- **许可证**: Server Side Public License
- **首次发布**: 2009
- **国家/地区**: US
