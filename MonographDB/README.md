# MonographDB

MonographDB is a propietary distributed DBMS based on MariaDB that uses a custom storage manager that stores data on a Cassandra cluster.

## 基本信息

- **数据库类型**: SQL、文档
- **所属机构**: MonographDB
- **许可证**: Proprietary
- **首次发布**: 2021
- **国家/地区**: CN
