# MyScaleDB

MyScaleDB is a hard-fork of Clickhouse that adds vector search and full-text indexing using Tantivy.

## 基本信息

- **数据库类型**: OLAP
- **所属机构**: Moqi Technology
- **许可证**: Apache v2
- **首次发布**: 2021
- **国家/地区**: CN
