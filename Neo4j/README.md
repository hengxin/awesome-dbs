# Neo4j

Neo4j is a graph database that leverages data relationships as first-class entities. It provides ACID Transactions with online backups and high availability. [01]

## 基本信息

- **数据库类型**: 图
- **所属机构**: Neo4j, Inc.
- **许可证**: 商业或开源（DB-Engines 未给出具体许可证）
- **首次发布**: 2007
- **国家/地区**: SE
