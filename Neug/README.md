# Neug

Neug is an embedded graph database system for analytics and real-time transactions.

## 基本信息

- **数据库类型**: 图、嵌入式
- **所属机构**: Alibaba Group
- **许可证**: Apache v2
- **首次发布**: 2026
- **国家/地区**: CN
