# NeuroDB

NeuroDB is a closed-source in-memory graph database engine.

## 基本信息

- **数据库类型**: 图
- **所属机构**: Pang Guoming
- **许可证**: Proprietary
- **首次发布**: 2020
- **国家/地区**: CN
