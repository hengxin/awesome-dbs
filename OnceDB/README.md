# OnceDB

OnceDB is a proprietary full-text search database based on Redis .

## 基本信息

- **数据库类型**: KV
- **所属机构**: OnceAI
- **许可证**: Proprietary
- **首次发布**: 2016
- **国家/地区**: CN
