# OpenEdge

OpenEdge is a relational database management system and integrated application development platform created by Progress Software Corporation. It targets online transaction processing workloads and provides tools for application development using its proprietary fourth-generation language alongside standard SQL interfaces.

Application development environment with integrated database management system

## 基本信息

- **数据库类型**: SQL
- **所属机构**: Progress Software Corporation
- **许可证**: Proprietary
- **首次发布**: 1984
