# OpenMLDB

OpenMLDB is a relational DBMS that purports to better support ML applications.

## 基本信息

- **数据库类型**: 时序、SQL
- **所属机构**: 4 Paradigm Inc.
- **许可证**: Apache v2
- **首次发布**: 2020
- **国家/地区**: CN
