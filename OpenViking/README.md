# OpenViking

OpenViking is an open-source context database designed for AI agents. It unifies the management of agent context, including memory, resources, and skills, through a virtual file system paradigm.

## 基本信息

- **数据库类型**: 文档、向量
- **许可证**: AGPL v3
- **首次发布**: 2026
- **国家/地区**: CN
