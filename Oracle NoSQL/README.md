# Oracle NoSQL

Oracle NoSQL Database (OND) is a distributed key-value DBMS. It use Berkeley DB (Java Edition) as its underlying storage manager on each node.

A multi-model, scalable, distributed NoSQL database, designed to provide highly reliable, flexible, and available data management across a configurable set of storage nodes

## 基本信息

- **数据库类型**: 文档、KV、SQL
- **所属机构**: Oracle
- **许可证**: 商业或开源（DB-Engines 未给出具体许可证）
- **首次发布**: 2011
- **国家/地区**: US
