# Oracle

Oracle database, originally a relational DBMS, has evolved into a converged, multi-model DBMS, e.g. it supports multiple types of workload (OLTP, data warehouse, operational data store, data hub), it can manage and join together multiple types of data (relational, XML, JSON, spatial, property graph, RDF, text, binary) being stored inside or outside the database, it supports numerous deployment…

## 基本信息

- **数据库类型**: SQL、文档、图、空间、向量
- **所属机构**: Oracle
- **许可证**: Proprietary
- **首次发布**: 1980
- **国家/地区**: US
