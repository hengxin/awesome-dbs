# Database Documentation
Oracle provides a range of industry-leading on-premises and cloud-based solutions to meet the data management requirements from small and medium sized businesses to large global enterprises.
## Get Started
### [Oracle AI Database](oracle/oracle-database/index.html)
The world's most popular database.
### [Oracle Autonomous AI Database](/en/cloud/paas/autonomous-database/index.html)
A set of Oracle Cloud data management services built on self-driving Oracle Autonomous AI Database technology to deliver automated patching, upgrades, and tuning, including performing all routine database maintenance tasks while the system is running, without human intervention.
### [Oracle Database Related Products](oracle/index.html)
Products related to Oracle Database that meet your database needs.
### [Database Cloud Services](database-cloud-services.html)
A comprehensive set of Oracle database cloud services providing traditional and modern solutions to deliver unmatched scale and performance for relational, graph, spatial, semi-structured, and unstructured non-relational data.
### [Data Integration](data-integration/index.html)
Oracle offers unique, next-generation products that help you to replicate data in heterogeneous environments, and process & analyze large-scale real-time information.
### [Other Databases](other-databases/index.html)
The world's most popular open-source database, MySQL, as well as innovative In-Memory and NoSQL database solutions
### [Big Data](/en/bigdata/index.html)
Oracle offers a broad and integrated portfolio of products to help you acquire and organize diverse data sources and analyze them alongside your existing data to find new insights and capitalize on hidden relationships.
### [Enterprise Manager](/en/enterprise-manager/index.html)
The Oracle Enterprise Manager family of products provides comprehensive enterprise management solutions for today's complex IT environments.
