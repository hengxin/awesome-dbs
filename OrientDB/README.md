# OrientDB

OrientDB is a multi-model NoSQL DBMS that supports graph, documents, key-value, and object-oriented storage. Instead of just implementing another layer with an API, OrientDB integrates those models. It also supports both disk-oriented and in-memory storages. Moreover, OrientDB supports SQL syntax with few differences from standard SQL and extends SQL syntax to support graph concepts. It is also…

Multi-model DBMS (Document, Graph, Key/Value)
