# OushuDB

Oushu Database (OushuDB) is a proprietary enhanced fork of HAWQ .

## 基本信息

- **数据库类型**: SQL
- **所属机构**: Oushu
- **许可证**: 商业或开源（DB-Engines 未给出具体许可证）
- **首次发布**: 2016
- **国家/地区**: CN
