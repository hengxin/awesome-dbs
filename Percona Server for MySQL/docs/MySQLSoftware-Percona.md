## Real Answers.
No Corporate Doublespeak.
Clear, direct answers about our software, support, licensing, and how things actually work in production.
####
What is the support cycle for MySQL software from Percona?
Our general policy is that we try to match our end-of-life dates for platforms to those of the upstream vendor. For software Percona produces based on upstream software, we match the upstream software’s end-of-life dates. In the same manner, as a platform or piece of software becomes outdated or is declared “end of life (EOL),” we move our engineering efforts to developing the next major release or addressing the next important piece of open source software. EOL software gets shifted back to Operational Support, and finally (as it is largely phased out in the broader ecosystem), to Community Support.
####
I want to migrate from MySQL CE or EE to Percona software for MySQL. How do I do it?
Percona software for MySQL is a 1:1 drop-in replacement for MySQL CE that enables you to migrate without additional code or configuration. All applications and data are fully compatible, and we offer open source solutions for achieving high availability during migration. Self-migrate using our documentation and Community Support. Alternatively, you can reach out to Percona MySQL Experts to ensure migration of your infrastructure with zero downtime, as well as Day 2 support after you migrate.
####
Is Percona Server for MySQL fully compatible with MySQL Community Edition?
Percona Server for MySQL is a complete drop-in replacement for MySQL CE that provides better performance, more scalability, and enhanced security features.
####
How do I use Percona for MySQL?
Consult the Quick Installation Guide for Percona Server for MySQL to install and start the product. If you want to use a Galera cluster, install Percona XtraDB Cluster.
