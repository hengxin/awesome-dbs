# PhotonDB

PhotonDB is an experimental key/value DBMS written in Rust.

## 基本信息

- **数据库类型**: KV
- **所属机构**: Huachao Huang
- **许可证**: Apache v2
- **首次发布**: 2022
- **国家/地区**: CN
