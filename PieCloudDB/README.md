# PieCloudDB

PieCloudDB is a cloud-native OLAP DBMS database. It supports both IaaS and bare metal deployments.

## 基本信息

- **数据库类型**: SQL、OLAP
- **所属机构**: OpenPie
- **许可证**: Proprietary
- **首次发布**: 2021
- **国家/地区**: CN
