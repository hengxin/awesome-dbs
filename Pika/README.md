# Pika

Pika is a C++ clone of Redis that uses RocksDB as its storage backend.

## 基本信息

- **数据库类型**: KV
- **所属机构**: Qihoo
- **许可证**: MIT License
- **首次发布**: 2014
- **国家/地区**: CN
