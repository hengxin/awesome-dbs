# Pinecone

Pinecone is a managed DBMS designed for storing and querying vectors using approximate nearest neighbor search.

A managed, cloud-native vector database

## 基本信息

- **数据库类型**: 向量、搜索
- **所属机构**: Pinecone Systems, Inc
- **许可证**: Proprietary
- **首次发布**: 2019
- **国家/地区**: US
