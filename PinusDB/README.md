# PinusDB

PinusDB ("Pinecone Database") is a time-series DBMS designed for IoT data sets.

## 基本信息

- **数据库类型**: 时序
- **所属机构**: ChangSha JuSong Soft
- **许可证**: GPL v3
- **首次发布**: 2019
- **国家/地区**: CN
