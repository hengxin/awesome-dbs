# PlanetScale
Copy page Copy page
PlanetScale is a relational database platform that brings you scale, performance, and reliability — without sacrificing developer experience.
Copy page Copy page
We offer [Vitess](/docs/vitess), [Neki](/docs/neki), and [PostgreSQL](/docs/postgres) clusters, powered by locally-attached NVMe drives that deliver unlimited IOPS and ultra-low latency.
## Vitess
Fully-managed Vitess clusters with unlimited scalability: sharding, branching, deploy requests, query insights, and more.
## Neki
Horizontal sharding for Postgres: data topology, query routing, online schema changes, and query insights.
## Postgres
Fully-managed PostgreSQL: high availability, query insights, branching, and more.
All clusters are deployed with one primary and a minimum of 2 replicas across 3 availability zones for high availability. Automated failovers, managed version upgrades, and a team of database experts holding the pager means you can spend your time shipping instead of worrying about your database.
For large-scale applications that are hitting the limits of vertical scale, [Vitess](/docs/vitess) provides horizontal sharding for MySQL-compatible workloads, and [Neki](/docs/neki) provides it for Postgres. You get query routing, built-in connection pooling, and a path to grow beyond a single primary.
