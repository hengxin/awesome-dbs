# Alibaba Cloud PolarDB

PolarDB is a commercial cloud based relational database product developed by the Alibaba. It is designed for clients with high read demand. PolarDB is compatible with two popular databases: MySQL, PostgreSQL. It has three layers. Users interact with database through computing layer. PolarFS is a distributed file system and polarStorage as storage level. PolarDB uses InnoDB as storage engine. [04]

## 基本信息

- **数据库类型**: SQL
- **所属机构**: Alibaba
- **许可证**: 商业或开源（DB-Engines 未给出具体许可证）
- **首次发布**: 2017
