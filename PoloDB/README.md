# PoloDB

PoloDB embedded document-oriented (JSON) DBMS written in Rust.

## 基本信息

- **数据库类型**: KV
- **所属机构**: Vincent Chen
- **许可证**: Apache v2
- **首次发布**: 2020
- **国家/地区**: CN
