# Qdrant

Qdrant is a vector-oriented DBMS.

A high-performance vector database with neural network or semantic-based matching

## 基本信息

- **数据库类型**: 向量、搜索
- **所属机构**: Qdrant
- **许可证**: Apache v2
- **首次发布**: 2021
- **国家/地区**: DE
