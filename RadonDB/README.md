# RadonDB

RadonDB is an open-source distribution layer for hosting MySQL in a cloud environment.

## 基本信息

- **数据库类型**: SQL、分布式
- **所属机构**: Yunify Technologies
- **许可证**: GPL v3
- **首次发布**: 2018
- **国家/地区**: CN
