# RapidsDB

RapidsDB is federated DBMS middleware with an in-memory OLAP execution engine. It provides a single query interface on existing PostgreSQL, MySQL, Oracle, and Hive databases.

## 基本信息

- **数据库类型**: OLAP
- **所属机构**: Boray Data Technology
- **许可证**: Proprietary
- **首次发布**: 2014
- **国家/地区**: CN
