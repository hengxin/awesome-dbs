# Realm

Realm is an open-source and object-oriented DBMS designed for the mobile devices. It supports multiple platforms such as Xamarine and Android. The system provides an object interface in programming languages including Objective-C, Swift, Java and C# for the OOP developers. A DBMS built for use on mobile devices that’s a fast, easy to use alternative to SQLite and Core Data
