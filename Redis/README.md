# Redis

Redis ("REmote DIctionary Server") is a networked, in-memory, key-value store that can be used as databases, cache or message broker. It supports storage of various types of data structures including strings, lists hashes and sets, as well as different kinds of queries on those data structures. Redis also provides support for on-disk persistent, Timed key expiration, LRU eviction of keys,…

## 基本信息

- **数据库类型**: KV、文档、图、空间、搜索、时序、向量
- **所属机构**: Redis project core team, inspired by Salvatore Sanfilippo Development sponsored by Redis Inc.
- **许可证**: BSD License
- **首次发布**: 2009
- **国家/地区**: IT
