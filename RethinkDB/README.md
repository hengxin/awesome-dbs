# RethinkDB

RethinkDB is an open-source JSON database management system written in C++. It is intended for the real-time web applications that require continuously updated query results.

DBMS for the Web with a mechanism to push updated query results to applications in realtime.

## 基本信息

- **数据库类型**: 文档、空间
- **所属机构**: The Linux Foundation since July 2017
- **许可证**: Apache v2
- **首次发布**: 2009
- **国家/地区**: US
