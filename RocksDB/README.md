# RocksDB

RocksDB is an embedded database using key-value data, and is developed by Facebook for high performance purposes.

Embeddable persistent key-value store optimized for fast storage (flash and RAM)

## 基本信息

- **数据库类型**: KV
- **所属机构**: Facebook, Inc.
- **许可证**: Apache v2
- **首次发布**: 2013
- **国家/地区**: US
