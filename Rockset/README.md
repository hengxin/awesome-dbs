# Rockset

Rockset is a cloud-based search and analytics database-as-a-service offering.

A scalable, reliable search and analytics service in the cloud, built on RocksDB

## 基本信息

- **数据库类型**: 文档、SQL、搜索、OLAP
- **所属机构**: Rockset
- **许可证**: Proprietary
- **首次发布**: 2019
- **国家/地区**: US
