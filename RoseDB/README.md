# RoseDB

RoseDB is a key-value DBMS that is compatible with the Redis wire protocol.

## 基本信息

- **数据库类型**: KV
- **所属机构**: RoseDB Labs
- **许可证**: MIT License
- **首次发布**: 2020
- **国家/地区**: CN
