# SQLite

SQLite is a self-contained, high-reliability, embedded, full-featured, public-domain SQL database engine. First released in August 2000, SQLite has several notable features which make it the most widely deployed database engine in the world.

Widely used embeddable, in-process RDBMS

- **数据库类型**: SQL
- **所属机构**: Dwayne Richard Hipp
