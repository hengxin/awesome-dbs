# SeekDB

SeekDB is an AI-native search database that unifies relational, vector, text, JSON, and GIS data models in a single engine. It supports hybrid search, in-database AI workflows, and offers both embedded and client/server deployment modes with MySQL compatibility.

## 基本信息

- **数据库类型**: 文档、SQL、向量、空间、嵌入式
- **所属机构**: Beijing OceanBase Technology Co., Ltd.
- **许可证**: Apache v2
- **首次发布**: 2025
- **国家/地区**: CN
