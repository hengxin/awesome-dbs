# ShannonBase

ShannonBase is a repackaged MySQL DBMS that uses a fractured mirror approach with a custom in-memory column storage engine. [06]

## 基本信息

- **数据库类型**: OLAP
- **所属机构**: ShannonAI, Inc.
- **许可证**: GPL v2
- **首次发布**: 2024
- **国家/地区**: CN
