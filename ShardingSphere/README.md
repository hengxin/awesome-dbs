# ShardingSphere

Apache ShardingSphere is positioned as a Database Plus, and aims at building a new criterion and ecosystem above multi-model databases. [02]

## 基本信息

- **数据库类型**: 多模型
- **所属机构**: Apache Software Foundation
- **许可证**: Apache v2
- **首次发布**: 2016
- **国家/地区**: CN
