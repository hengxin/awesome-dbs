# Snowflake

Snowflake is a cloud-based database and is currently offered as a pay-as-you-go service in the Amazon cloud. It is developed by Snowflake Computing.

Cloud-based data warehousing service for structured and semi-structured data

## 基本信息

- **数据库类型**: SQL、OLAP
- **所属机构**: Snowflake Computing Inc.
- **许可证**: Proprietary
- **首次发布**: 2014
