# Stardog

Stardog is a graph database management system.

Enterprise Knowledge Graph platform and graph DBMS with high availability, high performance reasoning, and virtualization

## 基本信息

- **数据库类型**: 图
- **所属机构**: Stardog-Union
- **许可证**: Proprietary
- **首次发布**: 2010
- **国家/地区**: US
