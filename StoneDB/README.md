# StoneDB

StoneDB is a columnar MySQL-compatible storage engine that supports OLAP workloads.

## 基本信息

- **数据库类型**: OLAP
- **所属机构**: StoneAtom
- **首次发布**: 2022
- **国家/地区**: CN
