# TDengine

TDengine is a open-source DBMS for time-series data.

Time Series DBMS and big data platform

## 基本信息

- **数据库类型**: 时序、SQL
- **所属机构**: TDEngine, previously Taos Data
- **许可证**: AGPL v3
- **首次发布**: 2019
