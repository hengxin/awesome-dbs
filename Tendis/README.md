# Tendis

Tendis is a distributed DBMS that is compatible with the Redis protocol.

## 基本信息

- **数据库类型**: KV
- **所属机构**: Tencent
- **许可证**: GPL v3
- **首次发布**: 2018
- **国家/地区**: CN
