# TensorBase

TensorBase is a OLAP query engine designed to execute on Apache Arrow data sets.

## 基本信息

- **数据库类型**: OLAP
- **所属机构**: TensorBase
- **许可证**: Apache v2
- **首次发布**: 2020
- **国家/地区**: CN
