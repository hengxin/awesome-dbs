# TerarkDB

TerarkDB was an embedded key-value store based on a fork from RocksDB (v5.18.3).

## 基本信息

- **数据库类型**: KV
- **所属机构**: ByteDance, originally Terark
- **许可证**: Apache v2
- **首次发布**: 2016
- **国家/地区**: CN
