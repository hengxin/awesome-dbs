# Titan

Titan is a distributed NoSQL DBMS that is designed to be compatible with the Redis protocol.

Titan is a graph database engine.

## 基本信息

- **数据库类型**: 图
- **所属机构**: Aurelius
- **许可证**: Apache v2
- **首次发布**: 2012
- **国家/地区**: US
