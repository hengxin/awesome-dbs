# Tonbo

Tonbo is an embedded, log-structured key-value DBMS that supports writing data to object stores. It also supports transferring data via Apache Arrow.

## 基本信息

- **数据库类型**: SQL
- **所属机构**: Tzu Gwo
- **许可证**: Apache v2
- **首次发布**: 2024
- **国家/地区**: CN
