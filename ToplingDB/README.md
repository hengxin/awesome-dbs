# ToplingDB

ToplingDB is a hard-fork of RocksDB with additional enhancements and features.

## 基本信息

- **数据库类型**: KV
- **所属机构**: Topling
- **许可证**: Apache v2
- **首次发布**: 2021
- **国家/地区**: CN
