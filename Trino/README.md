# Trino

Trino is a distributed SQL query engine designed to run on disparate storage systems.

Fast distributed SQL query engine for big data analytics. Forked from Presto and originally named PrestoSQL

## 基本信息

- **数据库类型**: SQL、文档、KV、空间、搜索、时序、宽列
- **所属机构**: Trino Software Foundation
- **许可证**: Apache v2
- **首次发布**: 2012
- **国家/地区**: US
