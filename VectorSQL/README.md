# VectorSQL

VectorSQL is an analytics DBMS designed for IoT data.

## 基本信息

- **数据库类型**: OLAP
- **所属机构**: Bohu Tang
- **许可证**: Apache v2
- **首次发布**: 2020
- **国家/地区**: CN
