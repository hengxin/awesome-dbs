# VeloDB

VeloDB is a real-time analytics and search database powered by Apache Doris. It provides both a managed cloud service (VeloDB Cloud) and an on-premise enterprise distribution (VeloDB Enterprise).

## 基本信息

- **数据库类型**: OLAP、搜索
- **所属机构**: VeloDB Inc.
- **许可证**: Proprietary
- **首次发布**: 2023
- **国家/地区**: CN
