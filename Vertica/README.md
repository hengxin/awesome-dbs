# Vertica

Vertica is a distributed, shared-nothing column-store DBMS.

## 基本信息

- **数据库类型**: SQL、空间、时序、OLAP
- **所属机构**: OpenText previously Micro Focus and Hewlett Packard
- **许可证**: Proprietary
- **首次发布**: 2005
- **国家/地区**: US
