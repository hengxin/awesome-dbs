# VictoriaMetrics

VictoriaMetrics Open Source is a fast and scalable open-source time series database and monitoring solution. It's designed to allowing users to build a monitoring platform without scalability issues.

A fast, cost-effective and scalable Time Series DBMS and monitoring solution

## 基本信息

- **数据库类型**: 时序
- **所属机构**: VictoriaMetrics
- **许可证**: Apache v2
- **首次发布**: 2018
