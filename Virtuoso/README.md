# Virtuoso

Virtuoso Universal Server is a middleware and database engine hybrid that provides an object-relational model.

Virtuoso is a multi-model hybrid-RDBMS that supports management of data represented as relational tables and/or property graphs

## 基本信息

- **数据库类型**: 文档、图、SQL、搜索、空间
- **所属机构**: OpenLink Software
- **许可证**: 商业或开源（DB-Engines 未给出具体许可证）
- **首次发布**: 1998
