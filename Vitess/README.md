# Vitess

Vitess is a middleware layer for scaling out MySQL.

Scalable, distributed, cloud-native DBMS, extending MySQL

## 基本信息

- **数据库类型**: SQL、文档、空间
- **所属机构**: The Linux Foundation, PlanetScale
- **许可证**: Apache v2
- **首次发布**: 2013
- **国家/地区**: US
