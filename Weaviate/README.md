# Weaviate

Weaviate is a vector DBMS that uses a custom query interface.

An open-source, AI-native vector database for search, RAG, and AI agents, with built-in vectorization, hybrid search, an agentic Query Agent, and Engram agent memory. Available self-hosted or as a fully managed service via Weaviate Cloud.

## 基本信息

- **数据库类型**: 向量、搜索
- **所属机构**: Weaviate B.V.
- **许可证**: BSD License
- **首次发布**: 2019
- **国家/地区**: NL
