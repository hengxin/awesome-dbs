# WebScaleSQL

WebScaleSQL was an open-source relational database management system built as a collaborative branch of MySQL 5.6, aimed at deployments managing large data volumes across many servers.

## 基本信息

- **数据库类型**: SQL
- **许可证**: GPL v2
- **首次发布**: 2014
- **国家/地区**: CN , US
