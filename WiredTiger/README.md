# wiredtiger

WiredTiger is an open-source key/value storage engine for NoSQL databases and is currently the default storage engine for MongoDB.

## 基本信息

- **数据库类型**: KV
- **所属机构**: WiredTiger
- **首次发布**: 2008
- **国家/地区**: AU , US
