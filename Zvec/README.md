# Zvec

Zvec is an in-process vector DBMS developed by Alibaba that supports dense and sparse embeddings, hybrid search combining semantic similarity with structured filters, write-ahead logging for data durability, and concurrent multi-process read access.

## 基本信息

- **数据库类型**: 向量
- **许可证**: Apache v2
- **首次发布**: 2023
- **国家/地区**: CN
