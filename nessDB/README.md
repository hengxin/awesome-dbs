# nessDB

nessDB is an embedded key-value DBMS written in ANSI C with BSD license. It does not require any external dependencies and works in most POSIX systems. [03] [04]

## 基本信息

- **数据库类型**: KV、嵌入式
- **所属机构**: Bohu Tang
- **许可证**: BSD License
- **首次发布**: 2011
- **国家/地区**: CN
