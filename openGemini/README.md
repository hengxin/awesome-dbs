# openGemini

openGemini is an open-source time-series database management system that is compatible with the InfluxDB wire protocol and query language.

## 基本信息

- **数据库类型**: 时序
- **所属机构**: Huawei and openGemini community
- **许可证**: Apache v2
- **首次发布**: 2022
- **国家/地区**: CN
